# 研究日志目录

本目录用于记录所有研究步骤、方向和内容。

## 目录结构

```
research/
├── logs/                   # 研究日志记录 (按 R001, R002... 编号)
├── templates/              # 日志模板
│   └── research_log_template.md
└── create_log.py          # 创建日志的脚本
```

## 使用方法

### 1. 创建新的研究日志

```bash
# 创建一个新日志（自动编号）
python research/create_log.py --topic "我的研究主题"

# 或者简写
python research/create_log.py -t "我的研究主题"
```

这会在 `research/logs/` 目录下创建一个格式为 `R001_2026-05-10.md` 的文件，并自动用编辑器打开。

### 2. 列出所有研究日志

```bash
python research/create_log.py --list

# 或者简写，显示最近10个
python research/create_log.py -l

# 显示最近20个
python research/create_log.py -l --number 20
```

### 3. 打开最新的研究日志

```bash
python research/create_log.py --latest
# 或
python research/create_log.py -n
```

## 日志内容说明

每篇研究日志包含以下部分：

1. **研究方向** - 研究背景、目标、范围
2. **研究过程** - 数据准备、因子分析、策略测试、回测设置
3. **研究结果** - 策略表现、回测分析、归因分析
4. **发现与结论** - 主要发现、结论建议、后续研究方向
5. **附录** - 代码、图表、参考文献、备注

## 研究记录最佳实践

### 及时记录
- 研究进行过程中随时记录，不要等全部结束再补
- 记录失败的尝试，同样有价值

### 详细完整
- 记录具体的参数设置
- 记录中间结果和思考过程
- 附上关键的图表和代码

### 结构化
- 按照模板结构填写
- 使用清晰的标题和段落
- 添加必要的链接和引用

### 持续更新
- 研究有新进展时随时更新日志
- 记录后续的验证和结果
