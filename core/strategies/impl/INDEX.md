> **最大回撤指标说明**：
> - **最大回撤** = 净值的最大峰谷跌幅（从顶到底的单向下跌幅度）
> - **回撤持续天数** = 从该次峰值下跌到谷底所经历的交易日数（下跌阶段长度）
> - **最大回撤修复天数** = 从谷底重新回升到前高所经历的交易日数（爬坑阶段长度）
>
> 修复天数 `<30d`=快速修复，`30~180d`=正常修复，`>180d`=修复偏慢，等于或接近全区间天数=存在永久性亏损


### 市场状态检测规则

| 状态 | 检测条件 | 说明 |
|:----|:--------|:----|
| 🐂 bull | 价在MA200之上 + MA20斜率>0 | 单边上涨趋势 |
| 🐻 bear | 价在MA200之下 + MA20斜率<0 + MA60斜率<0 | 全面下跌趋势 |
| 〰️ oscillate | 均线缠绕(MA5≈MA20≈MA60，偏离<3%) | 横盘整理 |
| 📈 recovery | 价在MA200之下 + MA5斜率突然转正 | 超跌反弹初期 |
