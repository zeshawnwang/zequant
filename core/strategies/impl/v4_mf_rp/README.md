# V4_MF_RP — V4原始多因子 + 无择时 + 10d + RP（多因子修正版）

> ❌ **三区间验证失败**：全区间Sharpe仅0.072，2022熊市大幅亏损-80.81%。数据经修正后收益大幅下调，不建议独立使用。

## 一句话总结

V4时代多因子选股（V2\_rf05因子权重+GTJA因子扩展） + 双周调仓 + 风险平价。

## 设计理念

- **选股器为什么选这个**：V4多因子选股器在V2的基础上扩展了因子库，使用rf05权重方案和GTJA补充因子。
- **择时器为什么选这个**：无择时。
- **仓位分配器为什么选这个**：风险平价。
- **调仓频率为什么选这个**：10d（双周）。

### 跨周期分析

V4_MF_RP是V1→V4过渡期的策略。年化5.41%大幅低于V1，全区间Sharpe仅0.072。2022熊市亏损-80.81%，回撤-84.17%为全策略库最高。牛市OOS虽有91.43%收益但波动剧烈，整体收益风险比不理想。

## 核心组件

### 选股器: MultiFactorSelector(V2_rf05+GTJA扩展)
- 参数：V2_rf05权重 + GTJA因子补充

### 择时器: 无

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 优缺点

**优点：**
- 去掉了V1的人工权重裁量权
- 因子库扩展增强了多样性

**缺点：**
- Sharpe 0.072远低于V1
- 回撤-84.17%为全策略库最高
