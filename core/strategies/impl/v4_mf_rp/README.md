# V4_MF_RP — V4原始多因子 + 无择时 + 10d + RP（多因子修正版）

## 一句话总结

V4时代多因子选股（V2\_rf05因子权重+GTJA因子扩展） + 双周调仓 + 风险平价。

## 设计理念

- **选股器为什么选这个**：V4多因子选股器在V2的基础上扩展了因子库，使用rf05权重方案和GTJA补充因子。
- **择时器为什么选这个**：无择时。
- **仓位分配器为什么选这个**：风险平价。
- **调仓频率为什么选这个**：10d（双周）。

### 跨周期分析

V4_MF_RP是V1→V4过渡期的策略。年化26.93%不及V1因为去掉了技术因子裁量权，但改进方向是正确的——减少人工干预。

## 核心组件

### 选股器: MultiFactorSelector(V2_rf05+GTJA扩展)
- 参数：V2_rf05权重 + GTJA因子补充

### 择时器: 无

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 优缺点

**优点：**
- 去掉了V1的人工权重裁量权
- 因子库扩展增强了多样性

**缺点：**
- Sharpe 0.976低于V1的1.119
- 回撤-28.71%偏高

## 最佳适用市场

- 最适用：多样化的市场环境
- 最不适用：极端行情

## 改进方向

- V4→V6的改进：使用V1最佳50因子+GA优化代替V2_rf05
- 叠加择时器
