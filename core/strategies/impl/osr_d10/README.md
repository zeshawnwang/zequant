# OSR_D10 — OversoldReboundSelector + 10d + RP（超跌反弹双周版）

## 一句话总结

基于真实OversoldReboundSelector信号的超跌反弹策略 + 双周调仓，从震荡市场中捕捉极端超卖后的修复机会。

## 设计理念

- **选股器为什么选这个**：OversoldReboundSelector基于真实信号筛选RSI<30、乖离率<-10%、缩量确认的超跌品种。在震荡市场中，超跌修复是可持续的alpha来源。
- **择时器为什么选这个**：无择时。超跌反弹本身就是一个择时信号，叠加额外择时器会破坏其自然周期。
- **仓位分配器为什么选这个**：风险平价（波动率倒数加权）。
- **调仓频率为什么选这个**：10d（双周）。超跌修复通常需要1~2周时间窗口，10d是自然周期。

## 核心组件

### 选股器: OversoldReboundSelector（基于真实信号）
- 参数：rsi_period=14, rsi_threshold=30, deviation_threshold=-0.10
- 关键因子：RSI<30, 乖离率<-10%, 缩量确认

### 择时器: 无

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 参数调优过程

对比了RSI阈值（25/30/35）和乖离率阈值（-8%/-10%/-15%），RSI=30+乖离率=-10%在选股数量和质量间取得平衡。

## 优缺点

**优点：**
- 超跌反弹有清晰的微观结构逻辑
- 震荡市中alpha稳定
- 与MF/Chip策略相关性低，适合组合

**缺点：**
- 回撤-26.39%偏高
- 持续下跌行情中可能失效

## 最佳适用市场

- 最适用：震荡市、超跌反弹行情
- 最不适用：单边下跌的熊市

## 改进方向

- 叠加择时器避免持续下跌中的连续买入
- 增加成交量和资金流确认
