# GA_D5 — GA优化+5d+RP（全量GA+新技术因子优化，最高收益）

## 一句话总结

全量66因子GA二次优化+周频调仓，实现全策略库最高年化收益(47.18%)，Sharpe 1.265，适合高收益偏好投资者。

## 设计理念

- **选股器为什么选这个**：使用X5 Pipeline的全量GA优化结果，对50个V1最佳因子+16个新技术因子进行二次权重优化。D5频率下GA找到了全66个因子的非零权重配置（全部有效），说明周频调仓需要更丰富的因子信号来捕捉短期alpha。
- **择时器为什么选这个**：无择时。GA_D5追求的是纯选股能力的极致发挥，择时器会干扰GA优化出的最佳权重结构。
- **仓位分配器为什么选这个**：风险平价（波动率倒数加权），在GA优化的因子权重之上，提供个股层面的波动率分散。
- **调仓频率为什么选这个**：5d（周频）。D5在年化收益上大幅领先D10(33.59%)和D3(11.39%)，说明**周频是GA优化框架下收益最大化的最佳频率**——比双周更能捕捉短期机会，比3d更低交易成本。

## 核心组件

### 选股器: MultiFactorSelector(GA优化权重)
- 参数：winsorize=0.01, top_n=40, normalize_weights=True
- 关键因子：66个全部非零权重因子（V1 50因子+16个新技术因子）
- 高权重因子：gtja13(1.94), gtja117(1.66), ma120_trend(1.29), a8(1.20), gtja185(1.08), ma_convergence(1.08)

### 择时器: 无
- 仓位系数逻辑：永远满仓(1.0)

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 参数调优过程

X5 Pipeline GA参数扫描（3个调仓频率）：
- **GA(rf=3)**：验证年化11.39%, Sharpe 0.333 — 频率太高导致信号衰减
- **GA(rf=5)**：验证年化47.18%, Sharpe 1.265, 回撤-29.11% ← 最高年化
- **GA(rf=10)**：验证年化33.59%, Sharpe 1.435, 回撤-16.33% ← 最高Sharpe

GA配置：npop=30, ngen=50, l1_lambda=0.005

## 优缺点

**优点：**
- 全策略库最高年化收益（47.18%）
- 胜率59.13%为所有策略最高
- GA优化覆盖全部66个因子，无信息浪费
- Calmar 1.620，单位回撤收益良好

**缺点：**
- 回撤-29.11%远超20%目标线
- 年化收益高但Sharpe低于GA_D10，风险调整后收益不是最优
- 66个因子全部参与，过拟合风险高于GA_D10（后者淘汰了5个因子）
- 无择时模块，熊市中防御能力弱

## 最佳适用市场

- 最适用：强牛市、结构牛、反弹市场（高收益弹性充分释放）
- 最不适用：熊市、高波动震荡市（回撤控制不足）

## 改进方向

- 叠加VolTiming择时降低回撤（参考mf_vol_d10_rp的做法）
- 与Chip_CovRP组合做资金分配，利用Chip的防御属性平滑回撤
- 增加训练/验证/测试三集分割，减少过拟合风险
- 用L1正则化压缩因子数量，保留最有预测力的30~40个
