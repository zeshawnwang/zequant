# Chip_Combo — Chip_CovRP(40%) + Chip_Equal(40%) + Chip_Vol(20%) 多信号融合组合

> ✅ **三区间验证通过**：全区间Sharpe>0.5，牛市OOS正收益，2022熊市基本持平

## 一句话总结

将三种Chip子策略（协方差风险平价、等权、VolTiming）按40/40/20资金分配融合，利用不同仓位分配方式的互补性平滑收益，熊市基本持平。

## 设计理念

- **选股器为什么选这个**：均使用ChipConcentrationSelector（筹码集中<5%, 量能萎缩<0.5, 均线粘合<5%）。选股逻辑一致，仓位分配方式不同。
- **仓位分配为什么选这个**：三种不同的仓位分配方式——CovRP（协方差风险平价，重视相关性分散）、Equal（等权，简单透明）、Vol（VolTiming择时，增加波动率防御）。40/40/20配比使CovRP和Equal主导，Vol择时作为补充。
- **为什么不用择时器**：Chip系列在熊市中几乎无交易，低波信号自动过滤了高跌幅品种，不需要额外择时。

### 跨周期分析

Chip_Combo将三种Chip子策略的资金分配融合，年化4.88%虽不高但回撤仅-11.90%。Chip系列在熊市中几乎无交易（低波信号自动过滤），组合后在熊市中基本持平。

## 核心组件

### 选股器: ChipConcentrationSelector（基于代理信号）
- 参数：max_volume_contraction=0.5, max_chip_concentration=0.05, max_ma_convergence=0.05

### 择时器: 无（由子策略各自管理）

### 仓位分配: 资金分配法（回测框架层实现）
- Chip_CovRP: 40% — 协方差风险平价
- Chip_Equal: 40% — 等权分配
- Chip_Vol: 20% — VolTiming择时

## 优缺点

**优点：**
- 三种仓位分配方式融合，分散化效果好
- 回撤-11.90%控制在较低水平
- 熊市中防御属性强

**缺点：**
- 年化4.88%偏低，牛市中可能大幅跑输指数
- 需要同时运行三个子策略，运维复杂度高
- OOS年化仅1.97%，稳定性需进一步验证

## 最佳适用市场

- 最适用：低波动震荡市、熊市防御
- 最不适用：快牛/暴涨行情
