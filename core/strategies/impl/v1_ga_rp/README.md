# V1_GA_RP — V1原始GA优化 + 技术因子裁量权+10d+RP（技术因子版）

## 一句话总结

V1原始GA优化50因子权重 + 16个技术因子手动权重（总和0.3裁量权） + 双周调仓 + 风险平价，年化45.46%为所有历史策略最高。

## 设计理念

- **选股器为什么选这个**：V1原始GA在训练集上优化了50个V1最佳因子的权重。16个技术因子（技术面特征，如均线、MACD、量能）被赋予总权重0.3的裁量权，手动调节权重。
- **择时器为什么选这个**：无择时。
- **仓位分配器为什么选这个**：风险平价。
- **调仓频率为什么选这个**：10d（双周），低频高收益。

### 跨周期分析

V1_GA_RP的年化45.46%为所有策略中最高，但回撤-39.77%也是最大的。技术因子裁量权（总权重0.3）显著提升了收益弹性，但也放大了风险。这是V1时代的最高收益策略。

## 核心组件

### 选股器: MultiFactorSelector(V1 GA权重 + 技术因子手动权重)
- 参数：V1 50因子GA优化权重 + 16个技术因子手动权重(总和0.3)
- V1 GA权重：ff_mkt, gtja142等
- 技术因子权重(总和0.3)：ma5, ma20, ma60, ma120, ma_alignment_score, ma60_trend, ma120_trend, macd_above_zero, macd_golden_cross, ma_angle_20, volume_breakout_ratio, volume_contraction, chip_concentration, ma_convergence, box_breakout, breakout_strength

### 择时器: 无

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 参数调优过程

V1时代的最佳发现。技术因子总权重0.3是经验值。

## 优缺点

**优点：**
- 年化45.46%为所有策略最高
- 技术因子切入了有效的技术面alpha

**缺点：**
- 回撤-39.77%为所有策略最高
- 技术因子手动权重缺乏客观依据

## 最佳适用市场

- 最适用：大牛市、强反弹行情
- 最不适用：任何会引发大幅回撤的环境

## 改进方向

- 使用GA自动优化技术因子权重代替手动赋值
- 择时器降低回撤
