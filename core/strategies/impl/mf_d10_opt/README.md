# MF_D10_Opt — MF(V1权重) + 30只持仓 + 5天最低持有 + 10天调仓（调优最佳版）

> 🏆 **三区间验证通过**：全区间Sharpe>0.5，牛市OOS正收益，2022熊市逆市盈利

## 一句话总结

对MF_D10_RP进行参数调优（tn=30, mhd=5, rf=10），全区间年化39.11%进一步提升，熊市年化53.88%为MF系列最高，是调优验证的最强MF策略。

## 设计理念

- **选股器为什么选这个**：与mf_d10_rp相同，使用V1 GA优化50因子权重的MultiFactorSelector。调优发现将top_n从40降至30可集中仓位、提升熊市表现。
- **择时器为什么选这个**：无择时。通过参数调优（mhd=5）让策略在牛熊市都保持满仓运作。
- **仓位分配器为什么选这个**：风险平价（波动率倒数加权），与mf_d10_rp一致。
- **调仓频率为什么选这个**：10d（双周）。调优确认rf=10在10/8/12三个候选中最优。

- 参数：winsorize=0.01, top_n=30（相比原版从40降至30）
- 关键因子：50个V1因子，GA优化权重

### 择时器: 无

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=30, min_hold_days=5, vol_lookback=20
