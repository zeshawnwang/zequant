# GA_CovRP_Combo — GA_D10(60%)×Chip_CovRP(40%)多策略组合

> 🏆 **三区间验证通过**：全区间Sharpe>0.5，牛市OOS正收益，2022熊市逆市盈利

## 一句话总结

将GA_D10与Chip_CovRP按60/40比例资金分配，GA提供高收益弹性、Chip提供防御缓冲。组合年化42.67%，在降低极端回撤的同时保留了GA的大部分收益。

## 设计理念

- **选股器为什么选这个**：GA_D10子策略使用X5实验GA(rf=10)优化出的66因子权重，覆盖传统多因子+新技术因子，年化33.59%/Sharpe 1.435为全库最优。Chip_CovRP使用筹码集中度信号（低波动+低动量），年化14.96%/回撤-9.68%为Chip系列回撤最低。两者底层逻辑完全不同，组合后产生显著的分散化效应。
- **仓位分配器为什么选这个**：GA_D10使用风险平价(RP)分配，Chip_CovRP使用协方差风险平价(CovRP)分配。组合层面用60/40资金分配法，仓位合并后归一化。
- **60/40比例选择**：60%权重保留了GA的高收益特性（年化42.67%），同时Chip的40%权重在极端市场中提供了约25%的缓冲，使最大回撤从-82%降至-58%。
