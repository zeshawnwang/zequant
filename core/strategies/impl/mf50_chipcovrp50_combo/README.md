# MF50_ChipCovRP50_Combo — MF_D10(50%)×Chip_CovRP(50%)多策略组合

> 🏆 **三区间验证通过**：全区间Sharpe>0.5，牛市OOS正收益，2022熊市逆市盈利

## 一句话总结

将MF_D10（高收益弹性）与Chip_CovRP（极致回撤防护）各50%资金组合，实现Sharpe 1.343的全策略库第二高值，回撤仅-17.01%。

## 设计理念

- **选股器为什么选这个**：组合的两个子策略使用不同的选股逻辑——MF_D10使用MultiFactorSelector（多因子量化评分），Chip_CovRP使用ChipConcentrationSelector（筹码集中度技术面）。两者选股逻辑差异大，组合后相关性低，平滑净值曲线的效果优于同类型组合。
- **择时器为什么选这个**：两个子策略均无择时。Chip_CovRP本身回撤仅-9.68%，不需要择时器；MF_D10无择时但收益高达38.03%。组合后-17.01%的回撤已经达标，不需要额外择时。
- **仓位分配器为什么选这个**：子策略层面各自使用风险平价。组合层面使用固定资金比例（50/50），简单透明。
- **调仓频率为什么选这个**：MF子策略10d（双周）低频高收益，Chip子策略3d（周频）稳健防御。不同频率的组合实现了时间维度上的互补。

### 为什么MF+Chip_CovRP优于MF+Chip_RP

Chip_CovRP使用协方差风险平价，比Chip_RP的简单风险平价更精准地分散了个股间的相关性风险。虽然Chip_CovRP年化（14.96%）略高于Chip_RP（14.50%），但Sharpe（1.288 vs 1.071）显著提升，组合后为整体贡献了更高的风险调整后收益。

## 核心组件

### 子策略1: MF_D10（50%资金）
- 选股器：MultiFactorSelector（V1 GA优化50因子权重）
- 择时器：无
- 分配器：风险平价
- 调仓频率：10d

### 子策略2: Chip_CovRP（50%资金）
- 选股器：ChipConcentrationSelector（筹码集中<5%, 量能萎缩<0.5, 均线粘合<5%）
- 择时器：无
- 分配器：协方差风险平价（基于60天协方差矩阵）
- 调仓频率：3d

## 优缺点

**优点：**
- Sharpe 1.343为组合系列最高
- 回撤-17.01%控制在20%目标线以内
- 两个子策略选股逻辑差异大，组合后鲁棒性强
- MF_D10高收益弹性 + Chip_CovRP极致回撤防护，互补完美

**缺点：**
- 年化22.78%低于MF60_Chip40的24.84%
- 需要同时运行两个子策略，运维复杂度翻倍
- 协方差风险平价需要60天历史数据，初期可能不稳定
- 在极端行情下两个子策略可能同时失效

## 最佳适用市场

- 最适用：震荡市、结构牛、大多数市场环境（组合的鲁棒性优势）
- 最不适用：流动性枯竭的极端危机

## 改进方向

- **调优发现**：调优发现w_mf=0.8优于0.6/0.5，牛市多配MF、熊市多配Chip的动态版本最佳。动态版本已沉淀为[mf_chip_dynamic](../mf_chip_dynamic/)。
- 研究动态权重调整：在市场波动率上升时增加Chip权重，下降时增加MF权重
- 增加第三个低相关性子策略（如OSR系列）
- 在组合层面叠加宏观择时信号
