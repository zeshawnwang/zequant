# Chip_RP — Chip+无择时+3d+RP（筹码集中低风险策略）

## 一句话总结

基于代理信号的ChipConcentrationSelector选股 + 无择时 + 周频调仓 + 风险平价，全程最大回撤仅-14.58%，是回撤控制最好的无择时策略之一。

## 设计理念

- **选股器为什么选这个**：ChipConcentrationSelector基于代理信号筛选筹码集中（chip_concentration<5%）、量能萎缩（volume_contraction<0.5）、均线粘合（ma_convergence<5%）的个股。天然偏好低波动+低动量品种，通过筛选低波动品种就具备了天然的防御属性。
- **择时器为什么选这个**：无择时（永远满仓）。-14.58%的回撤在无择时策略中极为罕见，说明Chip选股本身就有防御能力，不需要外部择时器。
- **仓位分配器为什么选这个**：风险平价（波动率倒数加权），与Chip选股的低波偏好形成双重低波保护。
- **调仓频率为什么选这个**：3d（周频）。筹码集中信号变化较慢，周频足够捕捉信号变化，降低交易成本。

### 跨周期分析

Chip_RP的无择时+低回撤组合在策略库中极为稀缺。年化14.50%虽不及多因子策略，但-14.58%的回撤完美控制在20%目标线以内。Chip选股的低波偏好与风险平价的双重低波保护是其核心优势。

## 核心组件

### 选股器: ChipConcentrationSelector（基于代理信号）
- 参数：max_volume_contraction=0.5, max_chip_concentration=0.05, max_ma_convergence=0.05
- 关键因子：筹码集中度、量能萎缩比、均线收敛度

### 择时器: 无
- 仓位系数逻辑：永远满仓(1.0)

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 参数调优过程

源自V8实验Chip_无择时_D3。筹码集中度阈值从5%到10%的参数扫描显示：<5%时选股池偏窄但质量最高，>10%时选股池扩大但回撤恶化。

## 优缺点

**优点：**
- 回撤控制优秀（-14.58%），在无择时策略中极为罕见
- 全程回撤在20%目标线以内
- Chip选股逻辑有清晰的微观结构支撑
- 无择时器意味着零择时失误成本

**缺点：**
- 年化14.50%低于多因子策略
- 在牛市中收益相对保守
- 筹码集中选股在极端流动性危机时可能失效
- 选股池偏窄，容量有限

## 最佳适用市场

- 最适用：震荡市、低波动市、熊市底部区域（防御属性强）
- 最不适用：快牛/暴涨行情、流动性骤降的危机模式

## 改进方向

- 叠加VolTiming波动率择时（如chip_vol_rp），以小幅收益换更优回撤
- 研究筹码集中度阈值优化：动态调整而非固定5%
- 增加量能突破确认条件，提升选股胜率
