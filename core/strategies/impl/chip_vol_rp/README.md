# Chip_Vol_RP — Chip+VolTiming+3d+RP（筹码集中+波动率风控）

> ✅ **三区间验证通过**：全区间Sharpe>0.5，牛市OOS正收益，2022熊市基本持平(年化-2%~+3%)

## 一句话总结

基于代理信号的ChipConcentrationSelector选股 + VolatilityTiming波动率择时 + 周频调仓，回撤仅-10.51%为所有策略中最低，是最佳防御型策略。

## 设计理念

- **选股器为什么选这个**：ChipConcentrationSelector基于代理信号筛选筹码集中的低波动品种，为波动率择时提供了天然适合的选股池。
- **择时器为什么选这个**：VolatilityTiming。对已持仓标的，波动率>30%卖出减仓，<15%持有。Chip选股+波动率择时形成双重低波保护（选股层+持仓层）。
- **仓位分配器为什么选这个**：风险平价（波动率倒数加权），与Chip选股+VolTiming的低波偏好形成三重低波保护。
- **调仓频率为什么选这个**：3d（周频）。Chip信号变化慢，周频足够。

## 核心组件

### 选股器: ChipConcentrationSelector（基于代理信号）
- 参数：max_volume_contraction=0.5, max_chip_concentration=0.05, max_ma_convergence=0.05

### 择时器: VolatilityTiming
- 仓位系数逻辑：波动率>30%卖出减仓，<15%持有
- 阈值：high_threshold=0.30, low_threshold=0.15

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

来自tune_chipvol系列调优（ht=0.15/0.2/0.25/0.3/0.35），验证了ht=0.25最优(熊市Sharpe 0.43 vs 0.34)。所有ht参数的年化接近（3.84%附近），说明Chip_Vol对VolTiming阈值不敏感。

## 优缺点

**优点：**
- 回撤仅-10.51%，所有策略中最低
- Sharpe 1.101优于无择时版本
- 三重低波保护机制，防御属性最强

**缺点：**
- 年化10.37%偏低，牛市可能跑输指数
- 双重低波过滤导致选股池进一步收窄
- VolTiming在V型反转行情中可能误判

## 最佳适用市场

- 最适用：低波动震荡市、熊市/高波动市场（防御最强）
- 最不适用：快牛/暴涨行情、V型反转行情

## 改进方向

- **调优发现**：ht=0.25最优(熊市Sharpe 0.43 vs 0.34)。
- 对比均值方差优化与风险平价的差异
- 考虑加入择时信号
