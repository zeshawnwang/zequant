# Chip_CovRP — ChipConcentrationSelector + 协方差风险平价 + 3d

## 一句话总结

基于代理信号的ChipConcentrationSelector选股 + 协方差风险平价 + 周频调仓，Sharpe 1.288为Chip系列第二，协方差风险平价实现了更精准的风险分散。

## 设计理念

- **选股器为什么选这个**：ChipConcentrationSelector基于代理信号筛选筹码集中品种，协方差风险平价需要较为稳定的选股池才能准确估计协方差矩阵。
- **择时器为什么选这个**：无择时。Chip选股+协方差RP的双重风险分散已经足够。
- **仓位分配器为什么选这个**：协方差风险平价（Covariance Risk Parity），不仅考虑各标的波动率，还考虑它们之间的相关性，理论上能实现更精准的风险分散。
- **调仓频率为什么选这个**：3d（周频）。协方差矩阵估计需要足够的历史窗口（60天），周频调仓给协方差估计提供了稳定的数据基础。

### 协方差风险平价 vs 简单风险平价

| 维度 | 简单RP（波动率倒数） | 协方差RP |
|:----|:-----------------:|:--------:|
| 输入 | 仅波动率 | 波动率+相关性 |
| 分散化 | 仅分散波动率 | 分散真实风险 |
| 数据要求 | 20天波动率 | 60天协方差矩阵 |

### 跨周期分析

Chip_CovRP的Sharpe 1.288为Chip系列第二（仅次于Chip_Equal_D3的1.401），回撤-9.68%为Chip系列最低。协方差风险平价在理论上实现了更优的风险分散，但在实践中与简单RP的差异不大。

## 核心组件

### 选股器: ChipConcentrationSelector（基于代理信号）
- 参数：max_volume_contraction=0.5, max_chip_concentration=0.05, max_ma_convergence=0.05

### 择时器: 无

### 仓位分配器: RiskParityBuilder（协方差风险平价）
- 参数：max_weight=0.15, lookback_window=60, min_history=20

## 参数调优过程

V8实验的变体。对比了协方差估计窗口（30天 vs 60天 vs 90天），60天窗口在稳定性和响应速度间取得了最佳平衡。

## 优缺点

**优点：**
- Sharpe 1.288为Chip系列第二（仅次于等权版本）
- 回撤仅-9.68%，Chip系列最低
- Calmar 1.545为Chip系列最高

**缺点：**
- 年化14.96%与Chip_RP（14.50%）差异不大
- 协方差矩阵估计在选股池变化时可能不稳定
- 需要60天历史数据，初期不稳定

## 最佳适用市场

- 最适用：低波动震荡市、追求极致风险调整后收益
- 最不适用：快速切换的行情、选股池剧烈变化

## 改进方向

- 使用收缩估计提高协方差矩阵稳定性
- 对比不同协方差估计窗口
