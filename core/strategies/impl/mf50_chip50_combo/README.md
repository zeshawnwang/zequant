# MF50_Chip50_Combo — MF_D10(50%)×Chip_D3(50%)多策略组合

## 一句话总结

将MF_D10与Chip_D3等权重（50/50）组合，回撤仅-16.60%为所有组合方案最低，是追求极致回撤控制的最佳选择。

## 设计理念

- **选股器为什么选这个**：等权重组合了MultiFactorSelector（多因子量化评分）和ChipConcentrationSelector（筹码集中度）两种完全不同的选股逻辑。MF提供高收益弹性，Chip提供回撤防护。50/50比例下Chip的防御效果得到充分体现。
- **择时器为什么选这个**：两个子策略均无择时。通过调整资金分配比例（50/50）来控制系统性风险，不需要额外择时层。
- **仓位分配器为什么选这个**：子策略层面各自使用风险平价。组合层面使用等权资金分配，简单透明。
- **调仓频率为什么选这个**：MF子策略10d（双周）追求低频高收益，Chip子策略3d（周频）保持稳健防御。

### 50/50 vs 60/40的选择

| 组合 | 年化% | Sharpe | 回撤% |
|:---|:----:|:-----:|:----:|
| MF60_Chip40 | 24.84 | 1.269 | -18.20 |
| **MF50_Chip50** | **22.29** | **1.257** | **-16.60** |

50/50比60/40少2.5%年化，但多1.6%的回撤保护。Sharpe接近（1.257 vs 1.269），说明两者在风险调整后收益维度差异不大。选择哪个取决于资金的风险偏好。

### 跨周期分析

MF50_Chip50的回撤-16.60%是V10所有组合方案中最低的。在2022年熊市中，Chip_D3的防御属性有效缓冲了MF_D10的跌幅。50%的Chip权重使得组合在大多数市场窗口中都能维持在20%回撤目标线以内。

## 核心组件

### 子策略1: MF_D10（50%资金）
- 选股器：MultiFactorSelector（V1 GA优化50因子权重）
- 择时器：无
- 分配器：风险平价
- 调仓频率：10d

### 子策略2: Chip_D3（50%资金）
- 选股器：ChipConcentrationSelector（筹码集中<5%, 量能萎缩<0.5, 均线粘合<5%）
- 择时器：无
- 分配器：风险平价
- 调仓频率：3d

## 优缺点

**优点：**
- 回撤仅-16.60%，所有组合方案中最低
- Sharpe 1.257表现稳健
- 等权重组合不需要判断哪种子策略更好
- 同时享受MF的高收益弹性和Chip的回撤防护
- 完美控制在20%目标线以内

**缺点：**
- 年化22.29%低于MF60_Chip40的24.84%
- 需要同时运行两个子策略，运维复杂度翻倍
- 牛市中对收益的拖累比60/40更明显
- 等权分配不一定是Sharpe最优解

## 最佳适用市场

- 最适用：震荡市、低波动市、追求绝对回撤控制的资金
- 最不适用：大牛市（过于保守，收益潜力未充分释放）

## 改进方向

- 作为MF60_Chip40的备选方案，用于不同风险偏好的资金
- 研究动态调整比例（根据波动率环境切换50/50或60/40）
- 将Chip_D3替换为Chip_CovRP，利用协方差风险平价进一步提升Sharpe
