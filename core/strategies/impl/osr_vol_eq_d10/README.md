# OSR_Vol_EQ_D10 — OversoldReboundSelector + VolTiming + 等权 + 10d

## 一句话总结

基于真实OversoldReboundSelector信号 + VolatilityTiming波动率风控 + 等权分配 + 双周调仓，在OSR基础上增加波动率防御层。

## 设计理念

- **选股器为什么选这个**：OversoldReboundSelector基于真实信号筛选超跌品种，+VolTiming择时做二次过滤。
- **择时器为什么选这个**：VolatilityTiming。对已持仓标的波动率>30%减仓，<15%持有。
- **仓位分配器为什么选这个**：等权分配。超跌反弹选出的股票波动率差异小，等权分配简单有效。
- **调仓频率为什么选这个**：10d（双周）。

### 跨周期分析

年化21.52%虽低于OSR_D10的23.55%，但回撤从-26.39%降至-16.43%，Sharpe从1.164升至1.280。VolTiming在OSR框架下的回撤改善效果优于其在MF框架下的表现。

## 核心组件

### 选股器: OversoldReboundSelector（基于真实信号）
- 参数：rsi_period=14, rsi_threshold=30, deviation_threshold=-0.10

### 择时器: VolatilityTiming
- 仓位系数逻辑：波动率>30%卖出减仓，<15%持有
- 阈值：high_threshold=0.30, low_threshold=0.15

### 仓位分配器: 等权分配（Equal Weight）

## 参数调优过程

在OSR_D10基础上叠加VolTiming择时。对比了风险平价与等权分配，等权在OSR框架下更优。
