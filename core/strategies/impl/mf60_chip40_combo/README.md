# MF60_Chip40_Combo — MF_D10(60%)×Chip_D3(40%)多策略组合

## 一句话总结

将MF_D10（60%资金）与Chip_D3（40%资金）组合，是V10最有价值的组合发现——同时达成年化>20%+回撤<20%的双重目标。

## 设计理念

- **选股器为什么选这个**：组合利用了MultiFactorSelector（多因子量化评分）和ChipConcentrationSelector（筹码集中度技术面）两种完全不同的选股逻辑。MF提供高收益弹性，Chip提供回撤防护，两者相关性低，组合后鲁棒性强。
- **择时器为什么选这个**：两个子策略均无择时。无择时的MF_D10年化38.03%，无择时的Chip_D3回撤仅-14.58%。组合后利用资金分配比例控制整体风险，不需要额外择时层。
- **仓位分配器为什么选这个**：子策略层面各自使用风险平价（波动率倒数加权）。组合层面使用固定资金比例（60/40），简单透明且有效。
- **调仓频率为什么选这个**：MF子策略10d（双周）低频高收益，Chip子策略3d（周频）稳健防御。不同频率的搭配实现了时间维度上的风险分散。

### 跨周期分析

MF60_Chip40是V10实验中最有价值的多策略组合发现。MF_D10在多因子框架下通过双周调仓实现了38.03%的年化，Chip_D3通过筹码集中选股实现了-14.58%的极低回撤。60/40的比例使组合同时满足年化>20%+回撤<20%的双重目标。

## 核心组件

### 子策略1: MF_D10（60%资金）
- 选股器：MultiFactorSelector（V1 GA优化50因子权重）
- 择时器：无
- 分配器：风险平价
- 调仓频率：10d

### 子策略2: Chip_D3（40%资金）
- 选股器：ChipConcentrationSelector（筹码集中<5%, 量能萎缩<0.5, 均线粘合<5%）
- 择时器：无
- 分配器：风险平价
- 调仓频率：3d

## 参数调优过程

V10实验对MF与Chip的多种资金分配比例进行了对比测试。核心发现：随着Chip权重增加，回撤线性下降，但收益呈非线性衰减。60/40比例是收益/回撤比最大化的甜点。

## 优缺点

**优点：**
- 同时达成年化>20%+回撤<20%的双重目标
- 利用策略低相关性平滑净值曲线
- 两个子策略均有独立验证，组合风险可控
- 60/40是收益/风控最佳平衡点

**缺点：**
- 需要同时运行两个子策略，运维复杂度翻倍
- 组合后换手率是两者之和，交易成本增加
- 极端行情下两个子策略可能同时失效
- 最优比例需要定期复核

## 最佳适用市场

- 最适用：结构性行情、震荡市（Chip的防御属性平滑波动）
- 最不适用：流动性枯竭的极端危机

## 改进方向

- 研究动态权重调整（根据近期市场环境切换60/40比例）
- 增加第三个低相关性子策略进一步平滑收益
- 在组合层面叠加宏观择时（如全市场估值信号）
