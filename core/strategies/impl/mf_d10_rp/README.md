# MF_D10_RP — 多因子+10d+RP（高收益低频旗舰策略）

> 🏆 **三区间验证通过**：全区间Sharpe>0.5，牛市OOS正收益，2022熊市逆市盈利

## 一句话总结

MultiFactorSelector(V1 GA权重50因子) + 双周调仓(10d) + 风险平价，年化38.03%为所有V1因子策略最高，是追求高收益的旗舰选股策略。

## 设计理念

- **选股器为什么选这个**：V1 GA优化50因子权重，GA在训练集上优化了因子的权重结构，D10频率的双周调仓降低了信号衰减率，让多因子评分有更长的有效期。
- **择时器为什么选这个**：无择时。D10（双周）低频高收益，择时器的频繁介入反而会破坏低频策略的自然走势。
- **仓位分配器为什么选这个**：风险平价（波动率倒数加权）。MF选出的股票波动率差异大，风险平价能在个股层面做波动率分散，比等权分配更优。
- **调仓频率为什么选这个**：10d（双周）。实验证明10d > 5d > 3d，低频调仓降低了交易成本和信号衰减。

## 核心组件

### 选股器: MultiFactorSelector(V1 GA权重)
- 参数：winsorize=0.01, top_n=40, normalize_weights=True
- 关键因子：50个V1因子，涵盖动量、反转、质量、成长、波动率、流动性等维度
- GA优化权重：ff_mkt, gtja142, gtja144等（V1最佳50因子）

### 择时器: 无
- 仓位系数逻辑：永远满仓(1.0)

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 优缺点

**优点：**
- 年化38.03%为所有独立选股策略最高
- 双周调仓低频省心（年化仅42次交易）
- GA优化因子权重有训练集验证
- Sharpe 1.306表现优秀

**缺点：**
- 回撤-30.44%远超20%目标线
- 无择时模块，熊市中跌幅较大
- 因子权重依赖于训练集，可能存在过拟合

## 最佳适用市场

- 最适用：结构牛、反弹行情（MF_D10的高收益弹性充分释放）
- 最不适用：单边暴跌（无择时无法减仓）

## 改进方向

- **调优发现**：top_n=30 + mhd=5 + rf=10 最优(熊市Sharpe 1.684 vs 原版1.105)。新版已沉淀为[mf_d10_opt](mf_d10_opt/)。
- 叠加择时器降回撤（如mf_vol_d10_rp加VolTiming）
- 与Chip策略组合降回撤
