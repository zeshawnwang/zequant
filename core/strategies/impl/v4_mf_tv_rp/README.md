# V4_MF_TV_RP — V4多因子 + TrendTiming + 10d + RP（多因子趋势择时版）

> ❌ **三区间验证失败**：全区间Sharpe仅0.114，2022熊市亏损-33.98%。数据经修正后收益大幅下调，不建议独立使用。

## 一句话总结

V4多因子选股 + TrendTiming趋势择时 + 双周调仓 + 风险平价。

## 设计理念

- **选股器为什么选这个**：V4多因子选股器在V2基础上扩展了因子库。
- **择时器为什么选这个**：TrendTiming（MA5>MA20做多，否则空仓）。
- **仓位分配器为什么选这个**：风险平价。
- **调仓频率为什么选这个**：10d。

## 核心组件

### 选股器: MultiFactorSelector(V2_rf05+GTJA扩展)

### 择时器: TrendTiming
- 仓位系数逻辑：MA5>MA20做多，MA5<MA20空仓
- 参考指数：上证综指(000001.SH)

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20
