# MF_Trend_D5_RP — 多因子+趋势择时+5d+RP（趋势跟踪版）

> ⚠️ **三区间验证**：全区间Sharpe>0.5，牛市OOS正收益，2022熊市亏损

## 一句话总结

MultiFactorSelector(V1 GA权重50因子) + TrendTiming趋势择时 + 周频调仓，利用指数均线作为市场择时器。

## 设计理念

- **选股器为什么选这个**：与MF_D10相同的V1 GA优化50因子权重，选股层不变。
- **择时器为什么选这个**：TrendTiming。当大盘指数（上证综指）MA5>MA20时做多（仓位系数1.0），否则空仓（仓位系数0.0）。趋势择时在熊市中完全空仓，防御能力最强，但在震荡市中频繁进出可能放大磨损。
- **仓位分配器为什么选这个**：风险平价（波动率倒数加权）。
- **调仓频率为什么选这个**：5d（周频）。趋势信号变化较快，5d能及时响应。

## 核心组件

### 选股器: MultiFactorSelector(V1 GA权重)
- 参数：winsorize=0.01, top_n=40

### 择时器: TrendTiming
- 仓位系数逻辑：MA5>MA20? 做多(1.0) : 空仓(0.0)
- 参考指数：上证综指(000001.SH)

### 仓位分配器: RPPortfolioWeights（风险平价）
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 优缺点

**优点：**
- 牛市OOS Sharpe 1.423表现稳健
- Trend逻辑简单，有止损止盈的心理优势

**缺点：**
- 全区间Sharpe 0.555低于无择时版本
- 趋势择时切入了太多收益，性价比不高
- 震荡市中频繁进出

## 最佳适用市场

- 最适用：单边牛市（不会触发空仓信号）
- 最不适用：震荡市、横盘整理

## 改进方向

- **调优发现**：buy_threshold=0.5比0.6更优(熊市Sharpe 1.41 vs 0.17)，但年化较低(3.71% vs 22.50%)。需要在收益和防御间权衡。
- 尝试混合策略：主策略使用bt=0.6追求收益，另配bt=0.5作为熊市对冲
- 考虑自适应threshold：根据市场环境动态调整
