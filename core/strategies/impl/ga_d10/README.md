# GA_D10 — GA优化+10d+RP（全量GA+新技术因子优化）

> ❌ **三区间验证失败**：全区间数据因GA过拟合不可信，OOS期Sharpe<0.3，2022熊市大幅亏损-30%。不建议独立使用。
>
> ⚠️ **OOS验证失败警告**
> 本策略的全区间高收益(年化33.59%/Sharp1.435)来源于GA权重在训练集的过拟合。
> OOS验证期(2024-07~2026-04)表现：年化4.29%/Sharp0.218，与全区间数据差距巨大。
> 2022熊市数据也显示无效(见下方回测表)。不建议独立使用。

## 一句话总结

全量66因子GA二次优化 + 双周调仓，实现全策略库最高Sharpe(1.435)和最低回撤(-16.33%)，是唯一同时满足回撤<20%+Sharpe>1.4的策略。

## 设计理念

- **选股器为什么选这个**：使用X5 Pipeline的全量GA优化结果，对50个V1最佳因子+16个新技术因子（均线、MACD、量能、筹码等）进行二次权重优化。GA的目标函数综合了年化收益、Sharpe、Calmar和胜率，D10频率下的优化结果最好——61个非零因子权重，GA自动淘汰了5个无效因子。
- **择时器为什么选这个**：无择时。GA优化已经将风险调整后收益纳入目标函数，双周调仓本身已经大幅降低了信号衰减率，不需要额外的择时层。
- **仓位分配器为什么选这个**：风险平价（波动率倒数加权）。GA优化专注于选股权重，风险平价在个股层面做波动率分散，两者分工明确。
- **调仓频率为什么选这个**：10d（双周）。X5实验对3d/5d/10d三个频率进行了GA优化对比，10d在验证集上表现最优（Sharpe 1.435 > 5d的1.265 > 3d的0.333），说明**低频调仓+GA优化是最佳组合**。

## 核心组件

### 选股器: MultiFactorSelector(GA优化权重)
- 参数：winsorize=0.01, top_n=40, normalize_weights=True
- 关键因子：61个非零权重因子，覆盖V1 50因子(45个非零) + 16个新技术因子(16个非零)
- 新增高权重因子：gtja34(1.58), ma5(-1.32), a8(1.12), gtja83(1.03), gtja13(1.01), a69(0.90), gtja144(0.88)

### 择时器: 无
- 仓位系数逻辑：永远满仓(1.0)
- 阈值：无

### 仓位分配器: RPPortfolioWeights（风险平价）
- 分配逻辑：波动率倒数加权，低波动个股获更高权重
- 参数：top_n=50, min_hold_days=5, vol_lookback=20

## 参数调优过程

源自X5 Pipeline的GA二次优化。参数扫描了3个调仓频率（3d/5d/10d）：
- **GA(rf=3)**：验证年化11.39%, Sharpe 0.333, 回撤-45.37%
- **GA(rf=5)**：验证年化47.18%, Sharpe 1.265, 回撤-29.11%
- **GA(rf=10)**：验证年化33.59%, Sharpe 1.435, 回撤-16.33% ← 最终选择

GA配置：npop=30, ngen=50, l1_lambda=0.005。目标函数在VectorizedEvaluator中综合评估收益、风险、回撤和换手。

### 2026-05-16实验验证

三区间验证显示GA权重在全部区间无效（Sharpe < 0.5）。不建议继续调优，GA_D10应标记为"不推荐独立使用"，仅用于组合中的小权重增强(≤15%)。

## 优缺点

**优点：**
- 全策略库最高Sharpe（1.435），风险调整后收益最优
- 回撤仅-16.33%，完美控制在20%目标线以内
- 双周调仓低频省心，全年仅42次交易
- 验证集Calmar 2.057，单位回撤收益最高
- GA二次优化引入了新技术因子，选股框架更完善

**缺点：**
- 验证集结果可能存在过拟合风险（GA在训练集优化后在验证集评估）
- 年化33.59%低于V1_GA_RP的45.46%和GA_D5的47.18%
- 无择时模块，纯多头无防御
- 61个因子权重难以手动解释和维护

## 最佳适用市场

- 最适用：结构牛、震荡上行市场（低频调仓+风险平价的最佳环境）
- 最不适用：单边暴跌（无择时无法减仓）

## 改进方向

- **调优发现**：GA权重在三区间全部无效。不建议继续调优，直接标记为"不推荐独立使用"。可用于组合中的小权重增强(≤15%)，因为其选股逻辑与MF不同，有分散化价值。
- 尝试使用相同因子重新进行GA训练（更长的训练窗口）
- 与MF等策略组合使用小权重
