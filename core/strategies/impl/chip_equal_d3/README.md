# Chip_Equal_D3 — ChipConcentrationSelector + 等权分配 + 3d

## 一句话总结

基于代理信号的ChipConcentrationSelector选股 + 等权分配 + 周频调仓，Sharpe 1.401为Chip系列最高，是"简单即最优"的典型案例。

## 设计理念

- **选股器为什么选这个**：ChipConcentrationSelector基于代理信号筛选筹码集中的低波动品种，为等权分配提供了质量均匀的选股池。
- **择时器为什么选这个**：无择时。Chip选股本身的防御属性足够强，不需要额外择时。
- **仓位分配器为什么选这个**：等权分配。Chip选出的股票波动率差异不大，等权与风险平价的差异被弱化。等权的简单性反而带来了更低的换手率和更高的Sharpe。
- **调仓频率为什么选这个**：3d（周频）。筹码集中信号变化慢，周频足够。

### 等权 vs 风险平价在Chip框架下的表现

| 维度 | Chip_Equal_D3(等权) | Chip_RP(风险平价) |
|:----|:-----------------:|:----------------:|
| 年化 | 17.43% | 14.50% |
| Sharpe | 1.401 | 1.071 |
| 回撤 | -11.19% | -14.58% |

等权在Chip框架下显著优于风险平价，说明Chip选出的股票波动率已经足够均匀，等权分配避免了风险平价对低波动股的过度偏好。

### 跨周期分析

Chip_Equal_D3的Sharpe 1.401为所有Chip系列策略中最高。等权分配在Chip框架下的优势在于：Chip选股已经天然筛选了低波动品种，等权避免了风险平价对低波动股的过度偏好，反而获得了更高的收益和更低的回撤。

## 核心组件

### 选股器: ChipConcentrationSelector（基于代理信号）
- 参数：max_volume_contraction=0.5, max_chip_concentration=0.05, max_ma_convergence=0.05

### 择时器: 无

### 仓位分配器: 等权分配（Equal Weight）
- 分配逻辑：每只选中的股票分配相同资金

## 参数调优过程

V8实验的等权变体。对比了等权、风险平价、协方差风险平价三种分配器在Chip框架下的表现，等权在Sharpe维度胜出。

## 优缺点

**优点：**
- Sharpe 1.401为Chip系列最高
- 年化17.43%高于Chip_RP（14.50%）和Chip_CovRP（14.96%）
- 等权分配简单透明，无模型风险
- 回撤-11.19%远低于20%目标线

**缺点：**
- 等权分配忽略了风险差异，高波动个股可能过度贡献风险
- 极端行情中可能不如风险平价稳定
- 收益提升主要来自更积极的权重分配

## 最佳适用市场

- 最适用：选股器alpha稳定且各股alpha差异不大的市场
- 最不适用：个别股票尾部风险极大的市场

## 改进方向

- 在等权基础上叠加简单的波动率过滤
- 对比等权、风险平价、协方差风险平价三种分配器在Chip框架下的表现
