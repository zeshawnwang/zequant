# MF_Chip_Dynamic — 动态权重: 牛市多配MF + 熊市多配Chip

> 🏆 **三区间验证通过**：全区间Sharpe>0.5，牛市OOS正收益，2022熊市逆市盈利

## 一句话总结

使用trend_p信号判断市场牛熊状态，牛市70%资金配置MF_D10（高收益弹性）+ 30%配置Chip_D3（防御），熊市切换为30%MF+70%Chip。全区间Sharpe 1.394，回撤仅-8.72%。

## 设计理念

- **为何动态切换**：固定权重组合（如mf60_chip40）在牛市中MF权重偏低限制了收益，在熊市中Chip权重偏低限制了防御。动态切换让每种市场环境下主力策略获得更高权重。
- **判断信号**：使用trend_p（趋势信号，取值范围-1~1）。trend_p > 0判断为牛市/震荡偏多，trend_p < 0判断为熊市/震荡偏空。
- **切换阈值**：trend_p=0作为牛熊分界线。 >0 → 70%MF+30%Chip; <0 → 30%MF+70%Chip。
- **子策略选择**：MF_D10（MultiFactorSelector + 双周调仓 + 风险平价），Chip_D3（ChipConcentrationSelector + 周频调仓 + 风险平价）。两者底层选股逻辑完全不同，组合后相关性低。

### 动态 vs 固定权重对比

| 组合 | 全区间年化% | Sharpe | 回撤% |
|:---|:----------:|:-----:|:----:|
| MF60_Chip40(固定) | 24.84 | 1.269 | -18.20 |
| MF50_Chip50(固定) | 22.29 | 1.257 | -16.60 |
| **MF_Chip_Dynamic** | **14.91** | **1.394** | **-8.72** |

动态版本在Sharpe和回撤控制上最优，说明动态权重分配确实改善了风险调整后收益。

## 核心组件

### 子策略1: MF_D10（牛市70%/熊市30%）
- 选股器：MultiFactorSelector（V1 GA优化50因子权重）
- 择时器：无
- 分配器：风险平价
- 调仓频率：10d

### 子策略2: Chip_D3（牛市30%/熊市70%）
- 选股器：ChipConcentrationSelector（筹码集中<5%, 量能萎缩<0.5, 均线粘合<5%）
- 择时器：无
- 分配器：风险平价
- 调仓频率：3d

### 动态分配器
- 信号：trend_p（趋势信号，取值范围-1~1）
- 牛市（trend_p > 0）：70%MF + 30%Chip
- 熊市（trend_p < 0）：30%MF + 70%Chip

## 优缺点

**优点：**
- Sharpe 1.394为组合策略系列最高
- 回撤仅-8.72%，所有组合策略中最低
- 动态切换逻辑清晰，牛熊市各自优化配置
- 两个子策略选股逻辑差异大，分散化效果好

**缺点：**
- 年化14.91%低于固定权重版本
- 依赖trend_p信号的准确性，信号失效时可能反向配置
- 需要同时运行两个子策略，运维复杂度翻倍

## 最佳适用市场

- 最适用：牛熊交替明显的市场（动态切换优势最大化）
- 最不适用：长期横盘震荡（趋势信号频繁切换导致交易成本增加）

## 改进方向

- 使用多信号综合判断牛熊（如加入宏观指标、资金流向）
- 考虑连续权重分配而非二值切换（如根据trend_p强度线性调整权重）
