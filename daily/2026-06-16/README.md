# 2026-06-16 V8因子权重优化：3种方案对比研究

## 背景

6-15全面回测确认V8简单翻转(8个reversal全翻转+2个dead降0)不是可靠升级：
- 全区间Calmar 7.05→4.96(-29.6%)
- 2022-2024结构性行情完全失效(Calmar=0)
- 因子翻转效果是regime-dependent的

本次研究3种更保守的方案，寻找兼顾OOS改善与全区间稳健的升级路径。

## 方法

综合评分 = 0.4 × 全区间Calmar + 0.3 × min(WF_OOS_Calmar) + 0.3 × 2022-2024_Calmar

V7基线评分 = 8.535 (Calmar=7.05, WF_min=0, 2022-2024=19.05)

### 方案1: Dead-only
仅移除2个dead因子(gtja142: 0.3005→0, gtja141: 0.2104→0)，其余48个因子权重不变。

### 方案2: Partial flip
翻转最稳定的2个reversal因子(gtja144: 0.2045→-0.2045, a41: 0.2152→-0.2152) + dead removal。

### 方案3: Regime-conditional flip
- 低波动期(40日滚动波动率 ≤ P85百分位): 使用V7+dead权重
- 高波动期(> P85): 使用全翻转+dead权重
- 波动率基于截面收益率标准差的40日滚动均值

### Regime-conditional工作原理

P85阈值意味着：仅当市场40日滚动波动率处于历史最高的15%时，才使用翻转权重。
- 约85%的时间使用V7+dead权重（稳健）
- 约15%的时间（极端波动期）使用翻转权重（捕捉反转机会）
- 这解释了为什么全区间Calmar大幅提升：在高波动期翻转有效(2019-2020)，
  在结构性行情保持原权重(2022-2024)避免了V8的致命问题

### Dead-only方案分析

Dead-only是"最小改动"方案：
- Calmar 7.05→8.09(+14.7%)，改善温和但稳健
- 移除gtja142(0.3005)和gtja141(0.2104)两个dead因子
- 这两个因子近期IC接近0，移除后信号噪声降低
- **推荐作为Regime-conditional的基线权重**

### Partial flip方案分析

Partial flip(gtja144+a41翻转)表现不如Dead-only：
- 虽然全区间Calmar更高(8.67 vs 8.09)
- 但2022-2024 Calmar大幅下降(12.48 vs 16.35)
- 说明即使只翻转2个因子，在结构性行情中仍有负面影响

## 结论

### 🏆 推荐方案: Regime-conditional flip (P85)

**V8-RC(regime-conditional)** 是最优升级路径：
1. 全区间Calmar +57%，Sharpe +35%，总收益 +156%
2. 2022-2024结构性行情Calmar仍为21.69(>V7的19.05)
3. WF OOS 3/4窗口非负(与V7持平)
4. 最大回撤仅-3.84%(与V7持平)

### 实现建议

1. **基线权重**: V7 + dead removal (gtja142=0, gtja141=0)
2. **翻转权重**: V7 + 8个reversal翻转 + dead removal
3. **Regime判断**: 40日滚动波动率 > P85百分位 → 使用翻转权重
4. **P85阈值**: 基于历史波动率分布的85%分位数，约0.024(截面收益率标准差)
5. **需监控**: 波动率阈值是否需要定期更新

### 风险提示

1. WF4(2025OOS)仍为Calmar=0，最新OOS期表现待验证
2. Regime判断基于历史波动率百分位，极端行情可能滞后
3. 翻转权重在高波动期的有效性依赖2019-2020数据，样本有限
