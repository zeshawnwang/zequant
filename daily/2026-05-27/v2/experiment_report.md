# mss_dynamic V2 全面优化实验报告

**日期**: 2026-05-27
**数据区间**: 2019-01-02 ~ 2026-05-22
**对比窗口**: 全区间 / 2022熊市 / OOS修复牛(2024.07+)
**方法**: autoresearch-inspired grid search + greedy combination

## 实验概述

本实验基于 V2b (增强ST+差异化止损) 和 V2c (V2b+置信度联动) 两个 baseline，
系统性地探索以下维度的优化空间：

| Phase | 内容 | 方法 |
|-------|------|------|
| 0 | Baseline 建立 | V2b/V2c 精确复制 |
| 1 | 10项改进单点消融 | 每项独立 × 2 baseline |
| 2 | 器级参数调优 | Grid search: 分配权重/止损/top_n/rf/mhd/置信度 |
| 3 | 组合优化 | Greedy additive, Calmar-driven keep/discard |

## Phase 2: 器级参数调优

### V2b 参数调优

- **分配权重**: 最佳=Bear适度进攻(4:3:3) (Calmar=2.355, Δ=+0.058)
- **止损比例**: 最佳=紧止损(6/8) (Calmar=3.469, Δ=+1.172)
- **子策略参数**: 最佳=mf系列rf=5 (Calmar=3.622, Δ=+1.324)

### V2c 参数调优

- **分配权重**: 最佳=Osc偏趋势(2:4:4) (Calmar=2.380, Δ=+0.010)
- **止损比例**: 最佳=紧止损(6/8) (Calmar=3.459, Δ=+1.090)
- **子策略参数**: 最佳=mf系列rf=5 (Calmar=3.674, Δ=+1.305)
- **置信度系数**: 最佳=激进降权(0.5/0.4/0.5) (Calmar=2.374, Δ=+0.004)

## 结论与建议

1. **V2b vs V2c**: 置信度联动是否带来增量价值？
2. **最有效单点改进**: 按 ΔCalmar 排名
3. **最有效参数调优**: 对每类参数的敏感度分析
4. **推荐组合**: 组合优化得到的最优配置
5. **OOS验证**: 在修复牛窗口(2024.07+)的表现是否稳健
