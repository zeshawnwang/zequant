## 2026-06-12 | 因子衰减监控与消融实验

| 字段 | 内容 |
|:-----|:-----|
| **背景** | 实盘因子衰减监控发现12条预警(10 critical + 2 warning)，8个因子IC方向反转(REVERSAL)，2个因子失效(DEAD) |
| **范围** | mf_d10_rp策略的50个因子，OOS期2026-04~06 |
| **方式** | autoresearch优化循环：6组消融实验(A0-A5) + IR时序诊断 + 窗口敏感性分析 + GA重优化 |

| **结论** | 8个reversal因子权重翻转是最稳健的改善方案；GA重优化过拟合不可用；简单方案优于复杂优化 |
| **影响范围** | 所有使用MF权重的策略(mf_d10_rp/mf_vol_d10_rp/c01_layered_d5/mf50_chip50/mf_trend_d5_rp/v1_ga_rp)均受影响 |
| **文件** | `daily/2026-06-12/` |

| A1: 降dead(gtja142/gtja141=0) | -0.79 | -1.27 | 11.45 | -9.00 | kept |
| A2: 剔除reversal(8因子=0) | 0.46 | 0.52 | 10.67 | 4.91 | kept |

| **范围** | 全部已沉淀策略(6个MF策略+2个非MF策略) + 实盘MSS混合策略4种市场状态 + V7 vs V8全区间回测 |
| **方式** | 阶段1: 简化回测OOS期(2026-04~06)；阶段2: 全面回测2018-2026(含MSS/分年窗口/WF验证/状态归因) |

## 2026-06-16 | V8因子权重优化：3种方案对比研究

| 字段 | 内容 |
|:-----|:-----|
| **背景** | 6-15确认V8简单翻转不是可靠升级(regime-dependent)，需寻找更保守方案 |
| **范围** | 3种方案: Dead-only/Partial-flip/Regime-conditional，11个配置参数组合 |
| **方式** | autoresearch优化循环，综合评分=0.4×全区间Calmar+0.3×WF_min+0.3×2022-2024 |
| **关键结果** | **Regime-conditional(P85)评分10.939，远超V7基线8.535**；Dead-only温和改善(8.141)；Partial-flip不如Dead-only |
| **结论** | V8-RC(regime-conditional P85)是最优升级路径：全区间Calmar+57%，Sharpe+35%，2022-2024仍稳健 |
| **影响范围** | 实盘MSS策略升级：基线权重V7+dead removal，高波动期(P85)切换翻转权重 |
| **文件** | `daily/2026-06-16/` |

### 详细结果

| 方案 | 评分 | Calmar | Sharpe | 总收益 | 2022-2024 |
|:-----|:----:|:------:|:------:|:------:|:---------:|
| V7基线 | 8.535 | 7.05 | 3.51 | 454% | 19.05 |
| Dead-only | 8.141 | 8.09 | 3.81 | 592% | 16.35 |
| Partial-flip | 7.212 | 8.67 | 3.58 | 552% | 12.48 |
| V8全翻转 | -1.008 | 4.96 | 2.86 | 180% | 0 |
| **Regime-P85** | **10.939** | **11.08** | **4.75** | **1162%** | **21.69** |

### ⚠️ 健壮性审计修正(同日)

审计发现Regime-conditional P85存在**前瞻偏差**(P85阈值使用全历史波动率分布含未来数据)。
修复前瞻偏差(改用滚动252日窗口)后：
- Regime-P85评分从10.939降至7.516(低于V7基线8.535)
- 前瞻偏差贡献31%的虚假改善
- **所有regime方案修复后均不如V7基线**
- **Dead-only是唯一可靠方案**: Calmar 8.09(+14.7%)，无前瞻偏差，2022-2024稳健
